# Проверка секретов и состава публикации

Дата: 1 октября 2026 года.

**Граница отчёта:** результаты ниже относятся к материалам, проверенным до версии 1.2.1. Изменения Issue #1 и локальные сборки 1.3.0/1.3.1 не входят в прежний аудит Git/секретов/релизных архивов. Новый полный аудит не выполнен. Владелец подтвердил основную работу версии 1.3.0; это не означает отдельной приёмки всех lifecycle-сценариев, Secure Input или новых AppKit-тумблеров 1.3.1 (build 6).

## Новое поведение 1.3.0/1.3.1 и границы проверки

По исходникам включение «Чистка клавиатуры» запрашивает Универсальный доступ только по действию пользователя и создаёт активный HID `CGEventTap`. В 1.3.1 меню использует системные NSSwitch и постоянные подписи; короткие статусы меняются внутри полей фиксированного размера. Отказ API/разрешения возвращает тумблер в фактическое состояние. Изменения этой версии касаются оформления; backend клавиатуры сохранён. Фильтр подавляет клавиатурные и доставленные медиасобытия всех устройств, включая внешние клавиатуры; Power пропускается, Touch ID не является обычным клавиатурным событием. Callback не читает символы и не сохраняет/логирует ввод. Мышь и scroll проходят с очищенными флагами клавиатурных модификаторов для сохранения обычного клика разблокировки; жесты не фильтруются.

Tap использует common run loop modes, включая tracking mode меню. После создания проверяется фактическая маска событий через `CGGetEventTapList`: активный tap, из маски которого macOS убрала клавиатуру, не считается блокировкой. При ошибке permissions/create/enable/read-back, системном отключении tap, сне, потере активной сессии и завершении блокировка снимается; автоматического re-enable и сохранения lock нет. Callback удерживает backend на время выполнения, handler использует слабую ссылку на контроллер, teardown отключает tap и освобождает source/port.

Локальные тесты работают с fake backend и синтетическими CGEvent, без реального запроса разрешения или event tap. UI-тесты 1.3.1 проверяют постоянство размера NSMenu и frames при всех состояниях и ошибках, а также сохраняют offscreen PNG настоящих AppKit views для визуального review. Эти PNG не являются скриншотами открытого системного меню. Они не доказывают доступность HID tap в установленной macOS, подавление системных сочетаний или поведение Secure Input. Фильтр не обещает аппаратное отключение клавиатуры. Выдачу прав, реальные события, sleep/session/выход и Touch ID/Power проверяет владелец перед публикацией; приложение не запрашивает sudo и не предлагает отключать защиту системы.

## Объём проверки

- Текущие публикуемые исходники, скрипты, SVG, plist и документация.
- Вся доступная на момент проверки история `main` и тегов: 3 коммита до реорганизации тестов, включая `948baad`.
- Скачанные с GitHub архивы приложения и исходников всех опубликованных релизов: `v1.1.0`, `v1.2.0`, `v1.2.1`.
- Имена файлов, Git-адреса авторов, содержимое архивов, контрольные суммы и состав приложения.

## Результат

**Gitleaks 8.30.1 не обнаружил секретов** в истории, текущих файлах и распакованных релизах. Сканер получен из официального репозитория `gitleaks/gitleaks`; контрольная сумма сверена с файлом его релиза. Значения потенциальных находок скрывались параметром `--redact=100`.

Не обнаружены `.env`, приватные ключи, сертификаты с ключами, файлы учётных данных или личные абсолютные пути `/Users/...` в опубликованных архивах. Git-коммиты используют публичный адрес GitHub noreply. Контрольные суммы скачанных ZIP совпали с опубликованными.

В прежних ZIP приложений присутствуют служебные записи macOS `__MACOSX`/AppleDouble. Они также просканированы, секреты не найдены. Новая команда упаковки исключает resource forks, расширенные атрибуты и quarantine metadata. Проверены отсутствие этих записей и сохранность подписи после распаковки нового ZIP. Уже опубликованные релизы не заменялись.

## Проверка поведения исходников

- Приложение загружает системный фреймворк по фиксированному абсолютному пути.
- Не содержит токенов, собственного сетевого клиента, чтения документов пользователя или буфера обмена, запуска shell-команд и запроса sudo.
- Единственный переход в сеть — открытие фиксированного адреса `https://dzzen.com/` с UTM-метками после нажатия ссылки пользователем.
- Сохраняется только выбранный режим Touch Bar в `NSUserDefaults`.
- Сборка использует инструменты Apple; сторонние библиотеки в приложение не включаются.
- При недоступном дисплее или API операция завершается сообщением, системная защита не отключается.

## Организация файлов

Тесты и их запуск находятся в `tests/`; результаты — в игнорируемом `build/tests/`. Сборки, архивы, временные диагностические файлы и инструменты аудита не входят в Git. В `.gitignore` добавлены типовые имена локальных настроек, ключей и сертификатов. Игнорирование файлов не заменяет сканирование уже отслеживаемых файлов и истории.

## Повторение проверки

При установленном Gitleaks:

```sh
gitleaks git . --log-opts=--all --redact=100 --ignore-gitleaks-allow
./tests/run.sh
./package.sh
```

Для проверки текущего некоммитнутого содержимого следует дополнительно запускать `gitleaks dir` по отдельной копии публикуемых файлов. Архивы релизов необходимо скачивать и проверять отдельно: сканирование Git само по себе их не охватывает.

## Ограничения

Это проверка заданного репозитория и его релизов, а не всего Mac или GitHub-аккаунта. Отсутствие находок не доказывает отсутствие любых уязвимостей. Сканер не гарантирует обнаружение неизвестных форматов секретов; выполнен также ручной просмотр небольшого объёма исходников.

Сохраняются известные ограничения: недокументированный API Apple, ad-hoc подпись без Developer ID и нотариализации, отсутствие проверок на всех моделях и версиях macOS. Отключение системной защиты не требуется и не выполнялось.
