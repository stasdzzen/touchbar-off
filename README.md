# Touch Bar Off

Маленькое бесплатное приложение для macOS: гасит и включает Touch Bar через переключатель в строке меню. В следующей локальной сборке **1.3.0 (build 5)** добавлена отдельная блокировка клавиатуры для чистки.

Создано, чтобы убрать раздражающее мерцание Touch Bar на MacBook Pro M1. В проверенном случае команда гашения остановила белые вспышки. Приложение не ремонтирует панель и не гарантирует такой же результат при любой неисправности.

**[Скачать приложение](https://github.com/stasdzzen/touchbar-off/releases/latest)** · **[Сообщить о проблеме](https://github.com/stasdzzen/touchbar-off/issues)**

## Возможности

В **1.2.1** фон кнопки рисуется явно, поскольку macOS может игнорировать системный `bezelColor`. Исправление проверено владельцем на MacBook Pro M1.

Изменения **1.3.0** пока проверены только локальными тестами и сборкой. Реальная блокировка клавиатуры на Mac владельца ещё не проверена; опубликованный релиз 1.2.1 её не содержит.

- Компактное системное меню macOS. Кнопка **Touch Bar**: красная — выбран режим гашения, зелёная — включения. Состояние также написано текстом.
- Ссылка **Dzzen.com** под кнопкой: `https://dzzen.com/?utm_source=touchbar-off&utm_medium=app&utm_campaign=menu`. Открывается в браузере только по нажатию.
- Кнопка **«Закрыть приложение»**. При выходе панель принудительно не включается.
- Сохранение выбора между запусками и повторение команды после сна.
- Независимая кнопка **«Заблокировать клавиатуру»** для чистки. При активном перехвате она меняется на **«Разблокировать клавиатуру»**; повторный клик трекпадом или мышью снимает блокировку.
- Монохромная иконка в строке меню, поддерживающая светлое и тёмное оформление macOS.

Нативный AppKit, без сторонних библиотек, фоновых сетевых запросов, встроенной аналитики, постоянного опроса и иконки в Dock. Не требует sudo или отключения SIP. Для клавиатуры нужно разрешение **Универсальный доступ**; управление Touch Bar этого разрешения не требует. Автозапуск не добавляется.

## Совместимость

Проверено на **MacBook Pro 13″ M1 (`MacBookPro17,1`), macOS 26.6.2**. Готовый ZIP предназначен для **Apple Silicon** и собран с минимальной версией macOS 13. Это нижняя граница сборки, а не обещание проверки всех версий macOS. На M2, Intel и других версиях системы работа не проверена.

Приложение использует внутренний API Apple `DFRBrightness.framework`. После обновлений macOS он может измениться. Блокировка клавиатуры не зависит от наличия Touch Bar или доступности DFR-клиента; при отсутствии панели её переключатель недоступен.

## Установка

1. В [релизах](https://github.com/stasdzzen/touchbar-off/releases/latest) скачайте `Touch-Bar-1.2.1-arm64.zip`.
2. Распакуйте архив и перенесите `Touch Bar.app` в папку «Программы».
3. Откройте приложение и нажмите иконку панели в верхней строке macOS.

При первом запуске выбирается **гашение**. Затем восстанавливается последний выбранный режим. Если нужно вернуть панель, включите переключатель.

## Чистка клавиатуры (локальная сборка 1.3.0)

1. Откройте меню приложения мышью или трекпадом и нажмите **«Заблокировать клавиатуру»**. Только это нажатие запрашивает Универсальный доступ.
2. Если разрешения нет, клавиатура остаётся доступной. В **Системных настройках → Конфиденциальность и безопасность → Универсальный доступ** разрешите `Touch Bar.app`, затем нажмите кнопку снова. При требовании macOS перезапустите приложение. Выдача разрешения сама блокировку не включает.
3. Начинайте чистку только после появления **«Клавиатура заблокирована для чистки»**. Для окончания нажмите **«Разблокировать клавиатуру»** мышью или трекпадом.

Фильтр действует на клавиатурные события всей пользовательской сессии, включая **внешние клавиатуры**; выбора устройства нет. Подавляются обычные клавиши, изменения модификаторов и доставленные tap события мультимедийных клавиш. Мышь, трекпад и прокрутка продолжают работать. Из событий указателя и прокрутки на время блокировки снимаются флаги Ctrl/Shift/Option/Command/Fn/Caps Lock, чтобы зажатый модификатор не мешал обычному клику разблокировки; остальные данные событий сохраняются. Другие события, включая жесты, не фильтруются.

**Touch ID и кнопка питания не блокируются.** Известные события Power явно пропускаются. Это фильтрация событий, а не полное аппаратное отключение: биометрия, Secure Input, системные сочетания и действия, обработанные macOS до event tap, не гарантированно подавляются. Блокировка работает только при успешно созданном и включённом активном HID event tap; fallback на более поздний session tap отсутствует. SDK Apple содержит ограничение HID tap для root, а фактическая доступность через Универсальный доступ зависит от macOS и ещё требует проверки владельцем. При отказе приложение оставляет клавиатуру доступной; повышать права не нужно.

Состояние клавиатуры не сохраняется: после запуска, выхода из приложения, сна или потери активной пользовательской сессии она доступна. После пробуждения блокировка сама не включается. При отключении tap системой (timeout/user input) приложение снимает блокировку, освобождает перехват и обновляет статус; автоматического повторного захвата нет. Статус подтверждает активность tap, а не физическое отключение всех клавиш. Открытие меню также перепроверяет активность tap. При принудительном завершении процесса системный tap исчезает.

Сборка имеет только локальную **ad-hoc подпись**, без Developer ID и нотариализации Apple. На другом Mac Gatekeeper может заблокировать скачанное приложение. ZIP — способ передачи, а не подтверждение доверия Apple. Альтернатива — самостоятельно собрать приложение из исходников ниже. Отключать системную защиту для сборки не требуется.

## Ограничения

- Переключатель показывает **выбранный режим**, а не измеренное аппаратное состояние панели.
- macOS может самостоятельно включить панель после системного события. После обычного сна программа повторяет выбранную команду; это поведение ещё не проверено реальным циклом сна.
- Не обещается отключение до входа в учётную запись, на экране блокировки или после закрытия приложения.
- Принятая команда гашения не доказывает физическое снятие питания с панели.

## Сборка из исходников

Нужны macOS и инструменты Apple Command Line Tools (`xcode-select --install`), либо установленный Xcode. Homebrew и сторонние зависимости не нужны.

```sh
git clone https://github.com/stasdzzen/touchbar-off.git
cd touchbar-off
./build-app.sh
open 'build/Touch Bar.app'
```

Скрипт собирает приложение под архитектуру текущего Mac. Публичный релиз собран на arm64; сборка и работа на Intel не проверены. Иконки генерируются локально средствами AppKit и `iconutil`.

Установить сборку в пользовательскую папку приложений:

```sh
mkdir -p "$HOME/Applications"
ditto 'build/Touch Bar.app' "$HOME/Applications/Touch Bar.app"
open "$HOME/Applications/Touch Bar.app"
```

Перед заменой уже установленного приложения закройте его через меню.

## Проверка и упаковка

```sh
./tests/run.sh
./package.sh
```

В `dist/` появятся ZIP приложения и контрольная сумма SHA-256. ZIP можно передать другому человеку; исходники также доступны через **Code → Download ZIP** на GitHub.

Проверки используют подставной клиент панели и **не включают настоящий Touch Bar**. Проверяются команды on/off, сохранение выбора при отказе API и отсутствие команд до готовности клиента или без доступного дисплея. Отдельный тест проверяет реально отрисованные красные и зелёные пиксели фона в светлом и тёмном оформлении, без переключения настоящей панели. Тест клавиатуры использует fake backend и синтетические события: не запрашивает разрешения, не создаёт настоящий tap и не захватывает ввод на Mac. Он проверяет ошибки permission/create/enable, клавиши/модификаторы/медиа, пропуск Power, мыши и scroll, снятие flags, fail-open, статус кнопки, sleep/session/terminate и освобождение объекта без retain cycle. Также проверяются plist, shell-синтаксис, компиляция с предупреждениями как ошибками и подпись bundle.

Фактически проверены гашение панели на указанном M1 и открытие меню приложения. Владелец также подтвердил корректное отображение исправленного меню версии 1.2.1. Физическое включение через переключатель, выход кнопкой, повторение после сна и установка на другом Mac пока отдельно не проверены. Наличие тестов не заменяет эти проверки.

Для 1.3.0 владельцу ещё нужно проверить разрешение и отказ, реальные клавиши/медиа/сочетания и внешнюю клавиатуру, сохранение клика/прокрутки при зажатых Ctrl/Shift, разблокировку той же кнопкой при открытом меню, Touch ID и Power, сон/смену пользователя/выход и повторный запуск без lock. Реальный захват ввода автоматическими тестами не проверялся; выдача разрешения и ручная проверка остаются за владельцем.

## Командная строка

При желании можно пользоваться только утилитой:

```sh
./build.sh
./touchbarctl off     # Погасить
./touchbarctl on      # Включить
./touchbarctl status  # Прочитать диагностическое состояние API
```

Числовые значения `state` недокументированы: не следует считать их надёжным доказательством включённого или выключенного дисплея. Для запуска двойным нажатием также сохранены файлы `Выключить Touch Bar.command` и `Включить Touch Bar.command`; перед использованием соберите `touchbarctl`.

## Исходники

| Файл | Назначение |
| --- | --- |
| `TouchBarApp.m` | Приложение в строке меню |
| `KeyboardLock.h`, `KeyboardLock.m` | Контроллер блокировки и системный backend активного HID event tap |
| `touchbarctl.m` | Консольная утилита |
| `assets/*.svg` | Векторные иконки |
| `render-icons.m` | Рисование PNG и набора размеров для ICNS средствами AppKit |
| `tests/test-app.m` | Проверки логики без настоящей панели |
| `tests/test-keyboard.m` | Проверки фильтра и lifecycle через fake backend без захвата клавиатуры |
| `tests/test-colors.m` | Проверки пикселей фона кнопки в светлом и тёмном оформлении |
| `tests/run.sh` | Запуск проверок; результаты в `build/tests/` |
| `build-app.sh`, `package.sh` | Сборка приложения и ZIP |

В приложении используются PNG 1×/2× для меню и ICNS для Finder. SVG служат редактируемыми векторными оригиналами; геометрия отрисовки также задана в `render-icons.m`.

## Удаление

Закройте приложение и удалите `Touch Bar.app`. Оно не устанавливает службы или автозапуск. Единственная сохраняемая настройка — выбранный режим в домене `local.touchbaroff.menubar`. При необходимости её можно удалить отдельно:

```sh
defaults delete local.touchbaroff.menubar
```
