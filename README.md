# Touch Bar Off

Бесплатное приложение для Mac: позволяет погасить Touch Bar и вернуть его через значок в верхней строке меню. Создано для MacBook с мерцающей панелью; приложение не ремонтирует Touch Bar.

Можно также временно заблокировать клавиатуру, чтобы её почистить. Трекпад и мышь продолжают работать.

**[Скачать приложение](https://github.com/stasdzzen/touchbar-off/releases/latest)** · **[Сообщить о проблеме](https://github.com/stasdzzen/touchbar-off/issues)**

Версия **1.3.1** включает управление Touch Bar и режим чистки клавиатуры.

## Как установить

1. Откройте [страницу последнего релиза](https://github.com/stasdzzen/touchbar-off/releases/latest) и скачайте **`Touch-Bar-1.3.1-arm64.zip`**. Это приложение для Mac с Apple Silicon; архив `source.zip` содержит исходники.
2. Распакуйте ZIP и перенесите **Touch Bar.app** в папку **«Программы»**.
3. Откройте приложение. Его значок появится в верхней строке меню, рядом с часами. Нажмите значок, чтобы открыть управление.

Для обновления скачайте новый ZIP и замените приложение вручную. Перед заменой старой версии закройте её через меню приложения.

Приложение пока не имеет подписи Developer ID и проверки Apple. Если macOS блокирует открытие и вы доверяете скачанному файлу, используйте **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**, как описано в [инструкции Apple](https://support.apple.com/ru-ru/102445). Отключать защиту Mac не нужно.

## Как пользоваться

- **Touch Bar:** включённый тумблер включает панель, выключенный гасит её. Выбор сохраняется между запусками. При первом запуске панель гасится.
- **Чистка клавиатуры:** включите тумблер перед чисткой. Когда появится «Заблокирована», клавиши перестанут передавать обычный ввод. Чтобы снова печатать, выключите **этот же тумблер трекпадом или мышью**.
- **Закрыть приложение:** завершает работу и снимает блокировку клавиатуры.

Для чистки macOS попросит разрешение. Откройте **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** и разрешите **Touch Bar**. Затем снова включите тумблер; если система требует перезапуск приложения, закройте и откройте его. Без разрешения клавиатура остаётся доступной. Для управления самой панелью это разрешение не требуется.

Если после обновления приложение просит разрешение снова, хотя **Универсальный доступ** уже включён, закройте Touch Bar. В этом разделе удалите старую запись кнопкой **«−»**, добавьте текущую установленную **Touch Bar.app** кнопкой **«+»** и включите разрешение. Затем откройте приложение снова.

Блокируются также **внешние клавиатуры**. **Touch ID и кнопка питания остаются доступны.** Блокировка не сохраняется после перезапуска приложения. Системные защищённые поля ввода и некоторые действия macOS могут обходить её — это не аппаратное отключение клавиатуры.

## Совместимость и подробности

Основная работа проверена владельцем на **MacBook Pro 13″ M1, macOS 26.6.2**. Проверок на Intel, других моделях и версиях macOS пока нет. Приложение не добавляет автозапуск и не требует sudo. На Mac без Touch Bar доступна только функция чистки клавиатуры.
